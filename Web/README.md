# 糯米学习 · Mochi Study 网页版

打开链接即可使用的学习搭子，无需下载、安装或登录。保留 Windows 项目，网页版单独实现和保存。

## 功能

- 今日四象限任务：新增、编辑、勾选、删除，按本地日期切换并保留历史。
- 银渐层小猫、糯米小兔、金毛小狗：独立命名，共用钱包与衣柜，呼吸和完成反馈动画。
- 番茄钟：专注、暂停、继续、短/长休息，可关联今日任务；迷你钟适合缩成浏览器小窗口。
- 完成专注才发金币：每完整专注分钟 1 金币；6 件物品购买一次、反复穿戴。
- 用眼提醒：默认 20 分钟提醒，支持 20 秒暂停休息与稍后提醒。
- DDL：为任务设置截止日期/时间，顶部展示最近 3 件未完成 DDL，支持提前 0、5、15、30、60、1440 分钟提醒。旧日期创建的 DDL 仍可在顶部编辑或完成。
- 一次性闹钟：自行填写名称和时间，启用/关闭/删除；到时页面内弹窗，可选系统通知。
- 学习足迹：每日目标、最近 7 天、累计时长/金币、最近完成记录。
- 本地存档：自动保存、上一份备份、导出/导入网页版 JSON；多标签页只允许一个页面修改。

## 使用边界

任务、DDL、闹钟、名字和进度仅保存在当前网站、当前浏览器中，不上传到服务器。浏览器清理数据、无痕窗口、换浏览器/设备/网址都会影响存档，请定期在设置中导出备份。Windows 与网页版暂不自动同步，也不互相导入存档。

计时需要页面保持打开。关闭、刷新、恢复页面后保留进度并暂停；浏览器挂起导致超过 5 秒未执行时也会暂停，不补算专注或金币。后台标签页可能被浏览器节流，因此不能保证后台长时间计时。

DDL 与闹钟采用当前系统时间检查。页面打开时触发页面内提醒；重新打开后会补提示尚未提醒的已到期事项，已完成的 DDL 不提醒。关闭网页后不会响铃，浏览器挂起、系统休眠或禁止通知时提醒可能延后。系统通知需要用户自行点击“开启系统通知”授权；提示音需页面发生过鼠标或键盘操作，且受浏览器声音权限影响。重要事项建议同时保留系统日历提醒。

网页版提供浏览器内迷你钟，不支持桌面置顶和透明窗口。宠物衣物使用浏览器原生表情图标展示，外观随系统有所不同。Windows 版继续提供独立窗口和置顶。

## 本地预览与修改

源码不依赖外部 JavaScript 库或联网字体；`dist` 为完整可发布目录。

在项目目录启动一个本地静态网页服务，例如：

```powershell
python -m http.server 5178 --bind 127.0.0.1 --directory dist
```

然后打开 `http://127.0.0.1:5178/`。直接双击 HTML 会受到浏览器模块和存储保护限制，开发预览请使用本地服务。

- `dist/index.html`：中文界面与弹窗。
- `dist/style.css`：颜色、布局、响应式样式和动画。
- `dist/app.mjs`：界面交互、保存、标签页锁、通知与提醒。
- `dist/domain.mjs`：任务、宠物、计时、金币、DDL 和闹钟逻辑。
- `dist/assets`：三个角色 PNG 与图标。
- `tests/checks.mjs`：16 项业务逻辑检查；`node tests/checks.mjs` 执行。

网站由 Sites 发布；`.openai/hosting.json` 保留唯一项目身份，后续更新复用此项目，不另建网站。角色图片为本项目生成的素材。项目暂未授予开源许可，详见 `COPYRIGHT.md`。
