# 糯米学习 · 朋友试用指南

这是一款 Windows 桌面学习搭子小游戏：用四象限安排任务，和小猫或小兔一起专注，积攒金币并给搭子换装。

## 下载和启动

收到项目的 GitHub 链接后，进入 **Releases（发布）** 页面，在对应版本的 Assets（附件）中下载 **Windows 运行包 ZIP**。请选 Windows 运行包；GitHub 自动提供的 Source code 是源码，不能直接双击运行。如果 Releases 还没有运行包，请向项目作者索取，暂时不用自行编译。

1. 关闭旧版糯米日程或糯米学习窗口。
2. 把 ZIP **完整解压**到你方便保存的位置，例如文档中的“糯米学习”文件夹。
3. 打开解压后的 `Windows` 文件夹，双击 `MochiStudy.exe`。

请保留 exe 旁边的文件和目录。以后移动程序时，移动整个 Windows 文件夹，不要只复制 exe。不需要安装 Unity 或 Visual Studio。

这是尚未进行代码签名的个人开发试用程序，没有认证承诺。Windows 可能显示下载或运行提示；请确认文件来自项目作者提供的正式仓库和对应 Release，按自己的判断决定是否运行，不需要关闭系统防护。

## 建议这样试一遍

先用“示例阅读”“练习题”等不涉及个人信息的任务试用：

1. **今日任务**：在四个“重要 / 紧急”象限中各建一项任务，修改名称或象限，再试着完成、取消完成和删除。
2. **日程搭子**：选择银渐层小猫，给它起名；切到小兔并另起一个名字，切回来检查两只搭子各自的名字。关闭后重启，看看名字和任务是否保留。
3. **专注空间**：默认一轮 25 分钟。为了快速试用，可以在设置中先把专注调为 **5 分钟**，选择一项任务并开始。试试暂停和继续，观察倒计时；完整完成 5 分钟应得到 5 枚金币。重置会放弃这一轮，中途放弃和休息不发金币。
4. **迷你钟**：切换为桌面一角的小窗口，移动它，再返回完整界面。专注中关闭并重新打开时，剩余时间应保留并暂停，需要自己继续。
5. **用眼提醒**：默认每 20 分钟有效专注提醒远眺至少 20 秒，可在设置中关闭或调整。单轮 5 分钟不会立即触发默认提醒；提醒不强制锁屏，也不自动暂停番茄钟。
6. **宠物小铺**：查看物品价格与购买、穿戴、卸下状态。完整专注积攒的金币才能购买，金币不足会提示；已购买的同一物品不会重复扣费。帽子、衣服、饰品各可穿戴一件。
7. **学习足迹**：查看完成的专注记录、今日进度和近 7 天柱图，试着调整每日目标。新用户还没有记录时，图表空白是正常的。

试用后可把专注时长改回默认 25 分钟。默认短休息 5 分钟，每完成 4 轮后的长休息为 15 分钟。

## 你的记录在哪里

任务、搭子名字、设置、专注记录、金币和衣柜保存在你的电脑：

```text
%LOCALAPPDATA%\MochiDay
```

把上面的路径粘贴到文件资源管理器地址栏即可打开。新版主存档为 `study.json`，上一份自动备份为 `study.json.bak`。设置中的本地备份功能会在此目录的 `Backups` 文件夹保存备份；也可以在关闭程序后复制整个数据目录。

如果你用过旧版，首次升级会导入 `days.json` 中的任务和历史，旧文件保留；新版后续进度写入 `study.json`。旧版和新版共享默认目录，请先关闭旧版再开新版。同一数据目录只允许一个实例。

更换或移动程序文件夹不等于删除上述个人存档。卸载试用文件前若想保留进度，请先备份数据目录；不要把自己的存档提交到 GitHub 或发到公开问题区。

## 试用边界

- 数据保存在本机，当前没有云同步、共享账号或跨设备恢复。
- 番茄钟计时不等于检测你是否在学习；程序不监控其他应用，也不统计全系统屏幕使用时间。
- 关闭、暂停和较大的休眠停顿不会补算专注金币。正常后台运行可以倒计时，离开电脑较久时建议先暂停。
- 跨午夜完成的一轮记入完成当天；日程自动切到新一天，未完成任务不自动顺延。
- 置顶属于可选窗口功能。透明、鼠标穿透、托盘和开机启动尚未加入。

## 怎么反馈

请使用同目录的 `FEEDBACK_TEMPLATE.md`，写清版本、Windows 环境、操作步骤和结果。截图尽量使用示例任务，裁掉姓名、聊天、邮箱等个人信息；报告问题通常不需要上传整个存档。

如果程序打不开、提示存档异常或进度丢失，先保留当前运行包并复制数据目录，再反馈。不要为了复现而删掉正式存档。
