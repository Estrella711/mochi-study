# 糯米学习 · Mochi Study v2

一只银渐层小猫或糯米小兔陪你安排今天、完成专注、积攒金币和换装。新版保留四象限待办，新增番茄钟、用眼提醒、搭子命名和金币衣柜。

## 开始使用

解压 Windows 运行包，双击 `Windows/MochiStudy.exe`。移动程序时请保留整个 Windows 文件夹，不能只复制 exe。日常使用不需要打开 Unity 或 Visual Studio。

升级前先关闭旧版 `MochiDay.exe`。新版和旧版共用默认数据目录，同一目录只允许一个程序实例，避免任务和进度相互覆盖。

窗口采用 Windows 标准标题栏：拖动标题栏移动，拖动边缘调整大小，通过右上角按钮最小化或关闭。可选置顶仅对本程序窗口生效。透明、鼠标穿透、桌面嵌入、托盘和开机启动尚未加入。

页面分为“今日任务”“专注空间”“宠物小铺”“学习足迹”。顶部可打开“设置”、切换“迷你钟”或开启置顶；侧边可更换搭子。迷你钟使用同一窗口，以约 **440 × 540** 的紧凑界面展示倒计时和搭子，适合放在桌面一角，随时可返回完整界面。

## 安排今日任务

四象限仍由“重要”和“紧急”两个选项决定：重要且紧急、重要不紧急、不重要但紧急、均不重要。新增任务后，可编辑名称和象限、勾选或取消完成、删除任务；旧任务保留在历史记录中。本机日期改变后自动切换到新的一天，未完成任务不会自动顺延。

完成任务会给搭子带来庆祝动画和精力、心情反馈。任务勾选的奖励属于当日状态，取消完成后重新计算；**金币由完整完成的番茄钟专注获得**。

## 番茄钟与金币

默认是 **专注 25 分钟 → 短休息 5 分钟**；每完成 4 轮专注，接下来的休息为 **15 分钟长休息**。专注结束后自行选择休息或下一轮，不会自动开始新的学习时间。

- 在“专注空间”开始前可选择今天尚未完成的任务作为本轮目标，也可自由专注；倒计时显示当前剩余时间。
- 暂停保留剩余时间，继续后接着计时；重置会放弃本轮进度并准备一轮完整专注。
- 完整完成一轮，按该轮设定时长 **每分钟 1 枚金币**奖励。例如完成默认 25 分钟获得 25 枚。中途停止、重置、休息和任务反复勾选不会发放金币。
- 修改专注设置后，正在进行的这一轮仍保留原时长与奖励，下一轮使用新设置。专注时长可设为 5–90 分钟。
- 关闭程序后重新打开，未完成的倒计时会保留进度并处于暂停状态，需要自行继续。离线时间不会换成金币。
- 电脑休眠或应用停顿造成的大时间间隔不计入专注。应用正常运行时可在后台倒计时；如果离开电脑较久，建议先暂停。

完成的专注会保留日期、学习目标、分钟数和实际获得的金币。跨越午夜的一轮记在**完成当天**。

“学习足迹”展示今日学习进度、近 7 天柱状图和专注记录。可在设置中调整每日目标，按自己的节奏积累完整完成的专注分钟数。

## 让眼睛歇一会儿

默认开启每 **20 分钟有效专注**一次的远眺提醒，可在设置中关闭或调整间隔。提醒会建议看向约 6 米以外的物体至少 20 秒；它不会强制锁定电脑，也不会自动暂停番茄钟。计数来自本应用的专注时间，不会监控其他应用或准确判断你是否一直看着屏幕。

这个提示参考美国眼科学会（AAO）的 **20-20-20** 建议：每使用屏幕 20 分钟，望向至少 20 英尺（约 6 米）远处至少 20 秒。[查看 AAO 官方说明](https://aao.org/eye-health/tips-prevention/are-computer-glasses-worth-it)。

## 选择和命名搭子

通过侧边“换搭子”在银渐层小猫和糯米小兔之间切换。两只搭子有独立名字：给小猫起名后切到小兔，不会把小猫名字覆盖；切回来仍会显示原来的名字。名字为 1–12 个字符，支持中文。

金币、衣柜和学习进度保存在同一份本地档案，两只搭子共用，不需要登录。

## 存档与旧版升级

默认数据目录为 `%LOCALAPPDATA%\MochiDay`。可在文件资源管理器的地址栏粘贴这个路径打开。

- 新版主存档：`study.json`，包括任务、历史、搭子名字、设置、倒计时、专注记录、金币和衣柜。
- 上一份新版备份：`study.json.bak`。
- 旧版任务存档：`days.json`。

如果首次打开新版时只有 `days.json`，会自动导入旧版任务、历史、窗口设置，并保留糯米小兔作为当前搭子。新进度保存到 `study.json`，**原 `days.json` 不会修改或覆盖**。随后启动优先读取 `study.json`；新版的后续修改不会反向写回旧版。

设置中的“导出本地备份”会在数据目录的 `Backups` 文件夹留下备份；也可直接复制整个数据目录备份个人进度。存档损坏时程序会尝试恢复上一份有效备份并保留损坏文件；无有效备份或存档来自更新版本时，会提示并保护原文件。遇到保存失败，先关闭程序并复制数据目录，再检查权限、磁盘空间或存档内容。

试玩时可用命令参数 `--data-dir "另一个完整目录"` 选择独立存档，不影响正式数据。所有记录在本机保存，不上传任务内容；存档没有加密。

## 在 Unity / 团结引擎中继续修改

1. 在团结 Hub 添加仓库根目录中的 `UnityProject`，用已安装的 **2022.3.61t14** 打开。若尝试其他 Unity 2022.3 版本，先复制项目，再重新导入和测试。
2. 顶部菜单仍使用 **Mochi Day** 名称。选择“准备场景与窗口设置”，再按 Play 查看程序。
3. 修改保存后等待引擎重新编译。界面和 2D 搭子由 C# 绘制，主要布局不在 Canvas Inspector 中调整。
4. 先运行 **Mochi Day → 运行存档与日期测试**，再执行 **Mochi Day → 构建 Windows x64**。构建输出为项目外侧的 `Windows/MochiStudy.exe`。

| 想修改什么 | 源文件 |
| --- | --- |
| 中文文案、颜色、页面布局与操作流程 | `Assets/Scripts/MochiApp.cs`、`StudyViews.cs` |
| 四象限任务、历史与存档迁移 | `Assets/Scripts/TaskDomain.cs` |
| 专注规则、金币、搭子名字、商店价格与物品 | `Assets/Scripts/StudyDomain.cs` |
| 小猫、小兔造型、动画和衣物绘制 | `Assets/Scripts/PetRenderer.cs` |
| 任务和学习功能自动检查 | `Assets/Scripts/CoreChecks.cs`、`StudyChecks.cs` |
| Windows 窗口初始位置与置顶 | `Assets/Scripts/WindowsWindow.cs` |
| Windows 导出设置 | `Assets/Editor/BuildProject.cs` |

**保留 `MochiDay` 命名空间。** 新版产品名变成 Mochi Study，但源码的原命名空间、引擎菜单和默认存档目录继续沿用。不要仅为改显示名称而批量改命名空间，也不要随意改存档字段名或版本号；需要更换存档结构时，先增加迁移逻辑和测试。

## 在 Visual Studio 中继续修改

打开随源码提供的 `MochiStudy.sln`，或在引擎中双击 C# 脚本。辅助代码工程继续使用 `UnityProject/MochiDay.Code.csproj`，用于编辑、跳转和检查，不是可以直接按 F5 运行的桌面程序；真正运行请回到引擎按 Play，或启动构建后的 exe。

复制仓库根目录的 `Directory.Build.props.example` 为 `Directory.Build.props`，填入本机引擎的 `Editor/Data/Managed/UnityEngine` 路径（也可通过环境变量或构建属性提供 `UnityManagedPath`）。这个本机配置不提交仓库。安装了 Unity IDE 集成时，也可在引擎 Preferences → External Tools 选择 Visual Studio，并重新生成工程文件；调试使用“附加到 Unity”。更多步骤见 [开发说明](DEVELOPMENT.zh-CN.md)。

建议一次修改一项行为：先在隔离存档中试玩，运行自动检查，再重新构建。发布前保留旧源码和个人存档备份。当前版本的测试范围和已执行结果见《验证记录.md》。
